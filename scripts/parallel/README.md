# 並行翻訳の道具（2026-11-08 の1000経の回で使ったもの）

**2026-11-08 以後は使わない。** ユーザーの決定で、翻訳は並列にせず1単位ずつ順に行う（並列にすると前の単位の訳を見られず、ゆれが増えたため）。記録として残す。

作業単位ごとに翻訳担当（同じ Claude、依頼文 v1）を並べて訳すときの道具。パスは Claude の作業場所（/home/claude/…）を前提にしている。

- AGENT_BRIEF.md：担当に渡した指示（決まり・手順・出力形式）
- build_compact.py：担当が書く「区切り番号<TAB>訳文」「#T」「#U」の形を、経典ごとの JSON に変え、区切り番号の過不足を確かめる
- ingest.sh：担当の出力を save_translation.py で保存し、文の数・字数・要確認の数を記録して点検する
- dump.py：経典の原文を区切り番号つきで出す

並行作業の注意：前の単位がまだ保存されていないと、品名・経題・摂頌・定型句を照合できない。担当はその箇所を uncertain に「前の単位と要照合」と書く。担当の報告は pali-ja-claude の terms/ja/claude-opus-5.5/留意点_1000経の回.md に残した。
