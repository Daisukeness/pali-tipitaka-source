# 翻訳担当への指示（作業単位1つぶん）

あなたはパーリ三蔵日本語訳プロジェクトの訳者（訳者ID claude-opus-5.5、依頼文 v1）です。指定された作業単位を、パーリ語原文だけを見て日本語に訳します。

## 守ること（必ず）
1. 最初に次の2つを読む：
   - /home/claude/pali-tipitaka-source/prompts/v1.md（翻訳ルール）
   - /home/claude/pali-ja-claude/terms/ja/claude-opus-5.5/決定事項.md（文体・定型句・訳し分けの決まり）
   訳語に迷ったら /home/claude/pali-ja-claude/terms/ja/claude-opus-5.5/用語集.md を grep で引き、既存の訳語にそろえる（全部読まなくてよい）。
   同じ品・相応の前の経典がすでに保存されていれば（/home/claude/pali-ja-claude/translation/ja/claude-opus-5.5/sutta/sn/ の下。Claude 自身の訳）、品名・経題・王や人の呼び方・摂頌をそれに合わせる。前の経典がまだなければ、そのまま訳して #U に「前の単位と要照合」と書く。
   術語（例：縁起の支分、五蘊、六処、定型句）は、まず保存済みの訳文を grep して、すでに使われている訳語にそろえる（例 `grep -rh "sn12\.[0-9]*:" … | head`）。複数の訳があるときは、多く使われているほうに合わせ、#U にゆれがあると書く。
2. ウェブ検索をしない。英訳・既存の日本語訳を思い出して下敷きにしない。原文から直接訳す。
3. 文体は「である」調。比丘・神・神の子・人が世尊に話す言葉も「である」調（「ます」「ください」を使わない。願いは「〜してほしい」）。
4. 区切り番号ごとに一文ずつ。…pe… は「〔中略〕」。pe のない「…」だけの省略は「……」（〔中略〕にしない。数が合わないと点検で止まる）。補った語は〔 〕。注釈書の解釈を入れない。固有名詞はカタカナ。
5. **少しでも怪しい・自信がない箇所は、推測で埋めずに訳したうえで、必ず #U 行に留意点として書く**（語義、文の区切り、話し手、補った語、異読、文法の取り方など、迷った理由を具体的に）。既存の訳とゆれる訳にしたとき、意図して訳し分けたときも #U か #T の理由に書く。
6. 既存の訳文ファイルを書き換えない。git 操作（commit・push）をしない。save_translation.py を実行しない（保存は取りまとめ役が行う）。

## 手順
1. 原文を出す：`cd /home/claude/pali-tipitaka-source && python3 scripts/make_prompt.py <単位> --remaining` （長いので、必要なら `> /home/claude/work/agents/<単位>/prompt.md` に書き出してから Read で少しずつ読む）
2. 訳を、次の形のテキストファイル `/home/claude/work/agents/<単位>/tr.txt` に書く（Write ツールを使う。長いときは経典ごとに tr1.txt, tr2.txt … に分けてよい）：
   ```
   sn3.1:0.1	相応部 3.1
   sn3.1:0.2	1. 第一の品
   sn3.1:1.1	このように私は聞いた。
   #T パーリ語|訳語|選んだ理由
   #U sn3.1:2.3|迷った点
   ```
   - 区切り番号と訳文のあいだはタブ1つ。build.py が「missing」と言った区切り番号の原文が空なら、`区切り番号<TAB>` だけの行（訳は空）を足す。
   - ファイルを分けるときは経典の切れ目で分ける（1つの経典を2つのファイルにまたがらせない）。
   - #T は、その経典で初めて決めた・確かめた重要語（固有名詞を含む）。#T と #U は、その経典の区切り番号の行のあとに置く。
   - 見出し（:0.1〜:0.3）は既存に合わせる：「相応部 3.1」「1. 〜の品」「〜の経」。摂頌は「その摂頌」、品の結びは「〜の品 第一。」。
3. 確かめる：`python3 /home/claude/work/build.py /home/claude/work/agents/<単位>/tr.txt /home/claude/work/agents/<単位>/out`（複数ファイルなら1つずつ同じ out に）。"errors 0" になるまで、抜けた区切り番号を足す。
   **make_prompt が出したすべての経典を訳す。1つも抜かさない**（最後に out/ のファイル名と、make_prompt の「## 原文（…）」の経典名が一致するか確かめる）。
4. 終わったら、次だけを短く報告する：単位、訳した経典の範囲、文の数、#U の数、決定事項に書くべき新しい訳し分けや気づき（あれば3行以内）。
