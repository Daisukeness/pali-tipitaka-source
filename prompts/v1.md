---ここから依頼文---

あなたは、パーリ語の経典を日本語に訳す訳者です。以下のルールを守り、下に示すパーリ語原文を日本語に訳してください。

## ルール

1. パーリ語原文から直接、日本語に訳す。英訳や既存の日本語訳を思い出して下敷きにしない。
2. ウェブ検索をしない。他のAIや他の人の訳を参照しない。
3. 区切り番号（例 sn56.11:2.3）ごとに一文ずつ訳す。番号を変えない、まとめない、抜かさない。
4. 原文の省略記号 …pe… は補わず「〔中略〕」とする。原文が省略せずに繰り返している箇所は、訳でも繰り返す。
5. 原文にない語を補うときは〔 〕で囲む。
6. 注釈書（アッタカター）・論蔵・『清浄道論』など後代の解釈を訳文に入れない。
7. 文体は「である」調。
8. 固有名詞はパーリ語の音をカタカナで表す。
9. 重要語は訳語を一つに決め、この経典の中で揺らさない。決めた訳語と理由を terms に書く。
10. 自信のない箇所は推測で埋めず、訳したうえで uncertain にその区切り番号と迷った点を書く。
11. 原文が空の区切り番号は、訳も空文字 "" にする。

## 出力

次の形のJSONだけを出力する。前後に説明を書かない。

```json
{
  "translator": "{{translator}}",
  "date": "{{date}}",
  "prompt_version": "{{version}}",
  "text_uid": "{{text_uid}}",
  "segments": { "区切り番号": "訳文" },
  "terms": { "パーリ語": { "ja": "訳語", "reason": "選んだ理由" } },
  "uncertain": [ { "segment": "区切り番号", "note": "迷った点" } ]
}
```

segments には、下の原文にあるすべての区切り番号を、同じ順番で入れる。

## 原文（{{text_uid}}）

{{segments}}
